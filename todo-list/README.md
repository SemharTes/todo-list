# GET IT DONE
A To-do List application built with React and Vite. Get It Done allows me/users to create and manage their daily tasks.

## Installation
clone the repo and install the dependencies:
```bash
git clone https://github.com/SemharTes/todo-list.git
cd <project-folder >
npm install
```

## Run the Develoopment Server
```bash
npm run dev
```

Then open the local URL provided by vite, usually:
```bash
http://localhost:5173/
```
